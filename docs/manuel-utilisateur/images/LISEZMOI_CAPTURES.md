# Captures d’écran pour le manuel

Placez ici les fichiers PNG (ou JPG) référencés par `../MANUEL_UTILISATEUR_SYSCO_FR.md`.

**Conseils**

- Résolution : **1280×720** ou plus, format **PNG** pour les interfaces.
- Masquez les données personnelles réelles (floutage ou jeu de données de test).
- Nommez les fichiers comme indiqué dans le manuel (`01-connexion.png`, etc.) pour que les liens fonctionnent.
- Sous **Windows**, utilisez *Outil Capture d’écran* (Win+Shift+S) ou *Snipping Tool*.

**Liste rapide des fichiers attendus** (voir tableau en fin du manuel pour le détail).

| Fichier | Écran |
|--------|--------|
| `01-connexion.png` | Page de connexion |
| `02-layout.png` | Fenêtre principale (menu + zone centrale) |
| `03-dashboard-admin.png` | Exemple tableau de bord |
| … | (voir manuel) |

Si une image manque, le lecteur Markdown affichera une image cassée : ajoutez le fichier ou commentez la ligne `![…](…)` dans le manuel.
